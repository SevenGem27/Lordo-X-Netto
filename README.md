# Lordo X Netto

Applicazione web progressiva per determinare il regime fiscale e contributivo delle somme corrisposte ai lavoratori dipendenti, con calcolo del netto, lordizzazione e costo azienda secondo la disciplina del periodo d'imposta 2026.

- App: https://sevengem27.github.io/Lordo-X-Netto/
- Pagina di presentazione: https://sevengem27.github.io/Lordo-X-Netto/presentazione.html
- Strumento correlato: [IndenniTool](https://sevengem27.github.io/IndenniTool/presentazione.html), calcolo del preavviso e delle indennità di fine rapporto nel CCNL del credito
